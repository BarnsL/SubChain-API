# Zhipu AI GLM

## Decision

Zhipu AI GLM is a direct API-key provider in SubChain. Use
`SUBCHAIN_ZHIPU_API_KEY`, `ZHIPUAI_API_KEY`, or `GLM_API_KEY`.

## Setup

1. Create an API key through the authorized Zhipu AI developer console.
2. Add it outside version control through one supported environment variable.
3. Select Zhipu AI GLM and a model from the Chain dropdowns, or point one local
   API key directly at the Zhipu provider from the Access page.
4. Verify the model list through that local key. It must not list models outside
   its target scope.

Treat the provider's current pricing, availability, and data-processing terms
as changeable. Verify them with the provider before relying on them.
